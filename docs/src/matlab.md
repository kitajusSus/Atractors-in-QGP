# LLE - Oryginalny kod w matlab 
Oryginalny kod matlab z zaimplementowanymi algorytmami LLE (ale przepisany na 
zdaty do interpretacji przez `GNU-Octave` kod) znajduje się w: 
- `matlab/lle/...`

Tam są wszystkie znalezione oryginalne kody
